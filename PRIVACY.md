# Privacy Policy: Clean Image Viewer

Last updated: 2026-10-22

Clean Image Viewer does not collect, transmit, sell or share any data.

- It makes no network requests. It reads only files that are packaged inside the extension.
- It does not read page content, browsing history, cookies, form data or the addresses you visit.
  The image address is never stored or logged.
- It keeps three things on your own device, in the browser's extension storage: its settings, the
  last version whose release notes you have seen, and a small capped activity log of the
  extension's own fixed messages (for example "Extension installed"). You can view, export and
  clear the log in the extension popup. Removing the extension removes this data.
- The "Feedback / support" and "Report an issue" buttons only open a web page (the store's support
  tab, or a new GitHub issue with the extension version prefilled). Nothing is sent by the
  extension itself; what you write on those pages is handled by the Chrome Web Store or GitHub.

Questions: open an issue at https://github.com/andrisoft/clean-image-viewer/issues.
